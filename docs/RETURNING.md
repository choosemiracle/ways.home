# 回归之路：四重视角与探索手记

## 思想与范围

本模块依据用户提出的宗旨与四位作者/传统的启发，设计一组可反复往返的阅读视角：认出热爱、形成表达、忠于生命、松开认同。它是本站的比较与应用设计，不是四位作者共同提出的学说，不是心理发展阶段或修行等级。

坎贝尔的英雄之旅本来就包含归来与回馈；Dan Koe 的创作/商业定位不是终极身份；帕尔默所说的真实自我与 ACIM 的 Self 保留各自语境。“你甚至不是那个故事”明确标为本站意译性概括，不作原典引文。上主之师、管道和使者只作为愿意服务的信仰表达，不构成免责或不可质疑的授权。

宗旨原文保留，并说明它是召集人的精神方向，来访者不必先认同全部形上主张。恐惧可以被承认，给予也容许休息、接受和求助；不把宽恕变成强制和解。

## 已实现内容

- `returning.html`：四重视角、来源与应用的区分、每一视角的价值/陷阱/校正、12 个开放问题、3 个明确标注的假设案例。
- `returning/explore.html`：同一件事的八栏手记，四个反思入口可以自由跳转。最后明确一小步、边界与复看方式。
- 日常语言与课程语言仅更换第四问的提示，不重写答案；两者不是神学等价翻译。
- 回归卡仅整理读者自己的原话；没有评分、画像、排名、推荐阶段或 AI 分析。
- 主页、导航、回到日常页、全站搜索与来源页均已接入。

## 原文与来源

七项来源统一加入来源页：Joseph Campbell Foundation 两项资料、Dan Koe 作者文章、Wiley 的帕尔默图书页、Foundation for Inner Peace 第 95/199 课，以及《教师指南》第一节的原典转录。

FIP 官方《教师指南》正文入口访问受限，第一节采用可检索的 Wikisource 原典转录核对，并在来源页明示；不冒充已经读取受限的官方页面。课程的神学陈述不充当科学或心理治疗证据。

## 维护入口

- `content/returning.json`：宗旨、四重视角、来源、案例。
- `scripts/returning.py`：模块与手记 HTML，交给公共页面生成器处理导航、语义标题与搜索。
- `assets/returning.css`：模块排版。
- `assets/returning.js`：手记交互，仅在手记页加载。
- `content/heading-breaks.txt`：标题与核心问题的统一语义断句。
- `tests/returning.spec.cjs`：11 项专门回归测试。

## 手记数据边界

默认不读取旧稿、不保存、不上传。主动保存才写入 `ways.home.returning.v1`；记录为 `version`、`language` 与八个文本字段。每栏最多 12,000 字符；读取时验证结构。重新访问时需要手动读取，避免在共享设备上自动显示隐私。

保存、读取、导出、清除各自独立。读取可能覆盖未保存草稿时需确认；清除仅删除本模块存储键，不影响旧练习。格式损坏、存储受阻或导出失败都有明确提示。原文通过 `textContent` 放入页面，不执行用户 HTML。未保存修改离开时触发浏览器确认；浏览器自身限制仍适用，不代替主动保存。

本地记录不加密、不跨设备同步。关闭 JavaScript 时，阅读与文字输入仍可使用，但需自行复制保存。

既有标题专项测试覆盖全部页面在 320 至 1920 像素的十种宽度，检查标题分句、词组、标点与溢出。桌面、平板与手机截图已复核。这不是全浏览器或完整无障碍合规审计。
