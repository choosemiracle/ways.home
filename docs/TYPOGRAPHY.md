## 单一编辑入口

`content/heading-breaks.txt` 保存语义分段。`|` 是词组间可换行的位置，`||` 是分句边界。移除分隔符后必须与原文逐字相同，不添加空格或改变标点。

```text
陌生人|与意见不同的人，||怎样有尊严地|生活在一起？
有限的生命，||怎样回应|超出自己的|意义与责任？
```

`TitleTypography` 在构建阶段处理所有 h1/h2/h3，保留标题链接。页首标题按分句换行；正文及卡片则根据容器宽度在分句与词组之间适应。原有闭合标点保留在前一词组，不使标点独占一行。

- `scripts/typography.py`：静态排版与运行时数据生成。
- `scripts/heading-runtime.js`：仅处理新增或变化的动态标题，生成 `assets/heading-layout.js`。
- `assets/heading-layout.css`：标题字号、行距与响应式规则。
- `scripts/audit_headings.py --check`：新增十字以上标题若无审校方案，构建检查会报错，避免再次依靠浏览器任意断字。

不要手工修改生成的 HTML 或 `assets/heading-layout.js`。
