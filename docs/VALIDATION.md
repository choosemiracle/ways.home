# 4.0 本地验证记录

本轮验证使用本机 Google Chrome 154 的独立自动化会话，测试路径为 `/ways.home/`。

## 已通过

- 30 个 HTML 页面生成成功，其中 29 个内容页、1 个 404 页。
- 1121 个本地链接与资源引用通过检查；没有缺失文件、缺失片段或重复 ID。
- 29 条全站搜索记录与已生成页面对应。
- JavaScript 语法检查与 `git diff --check` 通过。
- 30 项 Playwright 测试通过：原有 17 项与新增 13 项。
- 所有页面在 320、390、768、1440 像素宽度下无横向溢出。
- 筛选、空结果、重置、刷新恢复、搜索故障提示与重试通过。
- 比较选择、左右交换、刷新恢复、片段展开通过。
- 计时暂停、继续、结束、重置及二人练习半程换人通过。
- 记录不自动保存、主动保存、重载恢复、文字导出和清除通过。
- 存储失败时显示失败信息，不伪报保存成功。
- 关闭脚本时，正文与主要链接仍可阅读和导航。
- 首页桌面及手机版、阅读页、图谱页和比较页已生成截图供目视复核。
- 六篇深读、十二个概念词、十五个历史切面、十四个比较条目与三十七项来源检查通过。
- 五幅图像实际载入，保留比例、替代文本与署名，放大与 Escape 返回焦点通过。
- 同意前没有任何第三方视频网络请求、iframe 或远程缩略图请求。
- YouTube / Vimeo 使用允许名单域名、非自动播放、显式同意和可关闭播放器。
- 筛选隐藏视频时会移除播放器，不留下隐藏的播放。
- 四套应用的步骤时长加总准确，导出包含完整流程与边界。
- 导出失败有明确提示并支持重试；单项打印只显示所选流程。
- 不启用 JavaScript 时，图像、视频外链、导读和应用正文仍可使用。

## 范围限制

此记录不等于全部真实设备、全部浏览器或完整 WCAG 审计。来源内容仍应持续审校。视频测试使用模拟外部响应验证嵌入机制，不保证每个国家/地区都可播放，也不声称人工观看了视频全片。公开平台元数据与来源已核对，字幕与嵌入许可仍可能变化。GitHub Pages 部署结果需每次发布后另行核实，不能由本地测试推定。
