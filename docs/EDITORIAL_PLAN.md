# 同归 4.0：策划与编辑结构

## 读者旅程

首页不要求来访者先选择某个宗派。从一个问题进入，读一条道路，找到相邻与不同的解释，回到原典或研究，再带走一个日常练习。深度与速度由读者自己决定。

## 信息架构

四个阅读坐标提供入口；九条道路提供问题、方法、检验标准和张力；文明交汇提供时间、地点与具体文化语境；合一诸义负责防止概念混同；日常练习帮助阅读不只停在概念中。来源与边界贯穿全部专题，而不是装饰性的参考书单。

## 视觉结构

采用暖纸色、墨绿、克制的陶土色与细线。中文标题使用系统宋体，正文使用清楚的无衬线字体；英文作为辅助注释。首页的原创抽象山水结合水面、山势与等高线语言，是路径的比喻，不是对实际历史或地理的伪可视化。正文采取阅读栏与目录结构，避免大段文字挤进统一卡片。

## 不做的事

不把“回归”当成人类曾经完美的史实；不把原住民文化当作尚未进化的过去；不把所有非西方传统合并为一个整体论；不把科学、心理、宗教与审美的认识标准混用；不把不二、共融、人格整合与理论统一当成同一个结论。

不通过打卡排名、体验分数或不断弹出的内容挽留读者。没有强制注册，没有记录上传。离开网页、回到实际生活，本身就是设计允许的结果。

## 内容扩展规则

新增条目需说明具体语境与范围：谁、何时、在哪里，回应什么问题，采用什么方法，如何检验，可能有什么误用。至少提供能够支撑核心论述的来源；不足之处明确写出，不能以“万物相通”填补。

在添加更多道路以前，优先深化已有内容：补充思想内部的争论、相反观点、经典文本细读与可核实的案例。三十七项来源不等于三十七项最终答案。

## 4.0 的深化方法

六篇深读分别讨论事实与意义、合一的层次、艺术与观看、制度与共同生活、边界与回归、不同知识的相遇。每篇有六节完整论述，明示主张、提出一个真正的反对意见、给出有限回应，并保留后续问题。假设案例不冒充实地研究。

原有九条道路各补一节深化内容。文明交汇增加也门星盘、地球图像和共有资源研究三个切面；合一诸义增加一元论、共有资源治理、基默尔互惠论述与意识哲学四个入口。不通过添加名称制造一种已覆盖全世界的错觉。

## 图像与视频的角色

五幅图像是论述材料，不只是装饰。王蒙作品讨论流寓处境，北斋作品讨论观看的位置，梵高作品讨论形式与生平，星盘讨论知识与工艺的交织，暗淡蓝点讨论观测与伦理阐释。图像保留比例，不剪裁掉关键语境，注明馆藏/机构、日期与使用依据。

六段视频配中文导读、观看线索、问题与边界。大学课程、作者演讲、机构访谈与历史影像各有用途，不把它们当作同一种证据。视频不下载、不自动播放、不预载第三方缩略图；可用原平台链接作为播放受限时的替代入口。

## 从阅读到应用

四套原创流程服务于作品共读、轻微分歧讨论、共同空间规则与跨知识学习。流程明确时长、对象、材料、每步任务、具体产出、权限和安全边界，并提供 Markdown 导出与单项打印。复盘关注问题是否更清楚、规则是否可修正，而非追求情绪强度、共识或特殊体验。

## 后续范围

首批地图尚未系统展开犹太思想、耆那教、锡克教、伊斯兰科学史、东南亚、大洋洲及许多在地传统。未来扩展应优先邀请熟悉当地语言、历史与实践的人校正，而不是把新名字填进既定模板。
