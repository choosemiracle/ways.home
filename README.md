# 同归 · WAYS HOME

**Different Paths · One Common Purpose**

从真、善、美、归出发的一张人类探索图谱。共同的方向是编辑与实践上的愿望，不是预先宣布所有传统拥有同一个答案。

## 4.0：深读、视听与应用

本版在 3.0 图谱上增加六篇深度论述、十二个概念工具、五幅真实图像、六段作者或机构参考视频，以及四套可导出和打印的原创应用流程。原有九条道路也各增加一节深化内容，连接到相应深读与视频导读。

## 本版结构

新增「回归之路」：从坎贝尔、Dan Koe、帕尔默与《奇迹课程》得到四重可往返的视角，不是修行等级或心理发展测量。保留用户提出的宗旨，并用来源、区别、误用提醒、开放问题和假设案例支持探索。

- `index.html`：叙事式首页、四个问题入口和核心专题导览。
- `atlas.html`：九条探索道路，可按主题与关键词组合筛选。
- `paths/*.html`：每条道路的独立阅读页，包含方法、检验、张力与相关路径。
- `questions/*.html`：真、善、美、归四个阅读入口。
- `encounters.html`：十五个历史与当代切面，可按地区或交流网络筛选。
- `unity.html`：十四种不同语境的并读比较，选择可通过网址保留。
- `studies.html`、`studies/*.html`：六篇六节深读，包含主张、反对意见、回应、图像、视听导读与后续问题。
- `media.html`：五幅图像与六段视频，可筛选、检索；图像可放大，视频需主动同意才载入。
- `applications.html`：四套原创流程，分别为 60、45、60、75 分钟，包含材料、步骤、产出、适用边界与复盘，可导出 Markdown 或打印单项。
- `practice.html`：六种自愿的小练习，包含计时、暂停、书写、保存与导出。
- `returning.html`：认出热爱、形成表达、忠于生命、松开认同的四重视角；不把任何作者简化成高低阶梯。
- `returning/explore.html`：带着同一件事书写，整理个人回归卡；八个可留白字段、两种提问语言、主动本机保存/读取/导出/清除。
- `essay.html`：网站的编辑立场与思想框架。
- `sources.html`：四十四项来源及研究、隐私和实践边界。
- `404.html`：不存在的路径返回页。

共 31 个内容页面，另有 1 个 404 页面。本版不声称覆盖全部人类思想或文化。

## 编辑与数据

内容与来源在 JSON 文件中维护，原始条目和 4.0 补充内容在构建时合并：

| 文件 | 用途 |
| --- | --- |
| `content/atlas.json` | 九条道路的完整文字与关联 |
| `content/chapters.json` | 四个主题、历史切面、比较条目、练习和论述 |
| `content/sources.json` | 来源、类型、链接与适用范围 |
| `content/sources-extra.json` | 新增研究、馆藏与视听出处 |
| `content/depth.json` | 六篇深读、词汇、道路深化与新增比较/历史条目 |
| `content/media.json` | 图像、使用依据、视频标识与中文导读 |
| `content/workshops.json` | 四套原创应用流程及准确分钟数 |
| `content/returning.json` | 四重视角、原典来源、宗旨与假设案例 |

回归之路由 `scripts/returning.py` 生成，界面与交互由 `assets/returning.css` / `assets/returning.js` 维护，沿用统一标题断句。手记只在主动点击保存时写入 `ways.home.returning.v1`，重访不会自动显示旧文。读取旧记录需要主动点击；有未保存草稿时先确认。它不上传、不调用 AI，也不与其他练习存储混用。细节见 `docs/RETURNING.md`。

有研究依据的段落使用 `refs` 引用来源 ID；原创解释和伦理判断明确标为“本站阐释”。每一个引用在生成时检查，链接到阅读室的对应条目。勿用一个引用为超出来源范围的论断背书。

`scripts/build.py` 是 HTML、搜索索引与网站地图的生成入口；`scripts/enrichment.py` 负责富媒体和新增章节。不要手工修改生成的 HTML；请修改 JSON 或生成器，再重新构建。基础样式、脚本在 `styles.css` / `app.js`，新增功能在 `assets/enrich.css` / `assets/enrich.js`。

五幅已授权使用的图像保存在 `assets/media/`；`manifest.json` 记录源地址、使用依据、字节数与 SHA-256。需要重新取回缺失图像时运行 `python3 scripts/fetch_media.py`。此脚本不会下载视频。

## 构建与预览

需要 Python 3.12+。网站本身不依赖 Node 或第三方浏览器框架。

```sh
python3 scripts/build.py
python3 scripts/serve.py --port 8785
```

预览地址：`http://127.0.0.1:8785/ways.home/`

预览服务器只绑定回环地址，不开放目录列表。网站从 `/ways.home/` 子路径加载，测试与 GitHub Pages 项目路径一致。

## 验证

Node 18+ 用于开发测试。仓库锁定测试依赖版本；自动化默认使用本机 Google Chrome，不读取用户浏览器资料。

```sh
npm ci
npm run build
npm run check
npm test
```

静态检查覆盖页面主标题、语言、重复 ID、本地文件和锚点、搜索索引。Playwright 覆盖 320 / 390 / 768 / 1440 像素下的所有页面，以及搜索、筛选、比较、计时、记录和无 JavaScript 阅读。4.0 加入图像载入与放大、视频同意机制与关闭、资料筛选、流程导出与失败重试、单项打印等测试。

视频嵌入的自动化测试用模拟平台响应验证 URL、同意状态、非自动播放与关闭行为，不把测试结果当成每个地区都可播放的保证。

测试生成的 `preview-*.png`、`test-results/` 不提交到仓库。自动化验证不能替代内容审校、不同真实设备上的阅读体验或专业无障碍审计。

完成构建、测试与提交后，使用下面的正常快进推送同步两个分支；不要使用 `--force`。如果发布分支有独立改动，应先获取并协调这些改动。


仅推送 `main` 不会更新当前公开网站。每次发布后，都应检查 GitHub Pages 部署结果、首页和新增专题地址，而不是仅确认 Git 推送成功。

## 隐私与实践

本站没有账号、自建统计脚本或服务端笔记 API。全站搜索在浏览器中读取静态索引，不把查询发往第三方。

视频默认没有 iframe、外部缩略图或预连接；只有读者点击同意，才请求 YouTube 隐私增强播放器或 Vimeo 播放器。二者均不自动播放，并保留原平台链接。点击之后，平台将接收网络请求，可能应用自己的存储、广告与隐私政策；网站不能替平台作无追踪保证。关闭播放器会移除 iframe。视频为英语原声，字幕以原平台为准；本站中文导读不是逐字译稿，也不是完整字幕。

练习文字默认只在当前页面临时保留，主动点击保存才写入 `localStorage`。键名前缀为 `ways.home.notes.v1.`。这不是加密保险箱，存储也不是跨设备同步；共享设备应谨慎使用。读者可以导出文字或清除单项记录。

练习不是诊断、治疗、完整宗教修法或特殊体验承诺。随时可停止；边界、自主和问责，不因谈论“合一”而被取消。
