应用工坊 / APPLICATIONS

把哲思变成一场有边界的共同学习。

四套本站原创流程，适用于普通学习与日常协作。它们不是疗法、完整宗教修法或经过验证的效果保证；使用前先确认参与自愿及实际权限。

本站原创流程 / 4—12 人 · 观影沙龙、读书会或小组学习

从一件作品开始的共读

60 分钟

把描述、感受与解释分开，再让它们重新相遇。

准备材料

使用本网站的《神奈川冲浪里》全幅图。也可另选已获适当使用许可的作品；本流程不要求播放完整视频。

对应深读文章 ↗视频与中文导读 ↗
  1. 00—05 分

    建立约定

    允许不发言，不分析别人的心理；讨论作品时也保留个人感受的边界。

  2. 05—15 分

    静看与描述

    先各自观看，再每人指出一个画面里可以定位的细节，暂不总结寓意。

  3. 15—20 分

    分别书写

    两栏记录：我实际看见什么；我由此想到什么。

  4. 20—32 分

    两人交换

    每人六分钟，听完再问开放问题，不替对方解释他为何这样感受。

  5. 32—52 分

    补入语境并重看

    阅读馆藏简要说明，区分作者、馆方与自己的观点。再问第一印象发生了什么变化。

  6. 52—60 分

    带着问题结束

    每人留下一项新发现与一个尚未解决的问题，不要求统一结论。

可选的开放问题

  • 哪个细节支持这个解释？
  • 知道历史之后，什么改变了？
  • 不同感受能否同时存在？
具体产出

一张三栏记录：细节 / 自身回应 / 仍待核实的解释。

适用边界

不把审美偏好当成人格测验，不强迫披露个人创伤。

怎样复盘

检验是否更能指出具体细节、区分事实与联想，而非谁的感受更深。

本站原创流程 / 2—6 人 · 普通、低风险的日常分歧

一场不急于说服的分歧讨论

45 分钟

先辨认分歧发生在哪一层，再决定如何处理。

准备材料

每人带一个近期的轻微分歧，不使用涉及暴力、胁迫或显著权力不对等的情境。

对应深读文章 ↗视频与中文导读 ↗
  1. 00—05 分

    限定议题

    明确今天讨论的一个小问题，不给对方的全部人格下结论。

  2. 05—13 分

    列出已知与未知

    共同记录可核实的事实，以及需要另外求证的内容。

  3. 13—23 分

    说出珍惜的东西

    各自说明希望保护什么。另一方先复述，询问是否理解准确。

  4. 23—35 分

    提出不止一个方案

    至少列出两种行动，分别说明收益、代价与受影响的人。

  5. 35—45 分

    确定下一步

    决定是补资料、试行一个小安排，还是暂不作决定；明确谁负责与何时复核。

可选的开放问题

  • 我们争的是事实、解释、价值，还是行动次序？
  • 哪一条理由是对方真正关心的？
  • 有没有不必先解决全部分歧就能做的一步？
具体产出

一页共同记录：已同意 / 尚有分歧 / 待核实 / 下一步与复核时间。

适用边界

这不是治疗或危机调解。存在威胁与不安全时，不要求面对面对话，优先安全和合适支持。

怎样复盘

不以是否和好或一致为成功标准，而看问题是否更清楚，责任是否更可承担。

本站原创流程 / 4—10 人 · 共同空间、兴趣小组或志愿团队

为一处共同空间设计可修正的规则

60 分钟

把共同价值变成谁都能看见、能够质疑的具体安排。

准备材料

使用“十户居民共用阅读室”的原创假设案例，或一个参与者确有权讨论的真实小问题。

对应深读文章 ↗视频与中文导读 ↗
  1. 00—05 分

    说明决定权限

    今天是收集意见还是作出决定？哪些事项需要其他人的授权？

  2. 05—15 分

    画出资源与责任

    分别列出谁使用、谁维护、谁承担成本、谁决定规则。

  3. 15—30 分

    起草一条规则

    先处理一个最具体的问题，例如预约与轮换。说明适用范围与例外。

  4. 30—45 分

    用反例测试

    分别模拟忙碌缺席者、弱势使用者、重复违规者，检查是否仍然公平可行。

  5. 45—55 分

    修订与记录

    说明如何提醒、提出异议、复核与修改；不要把处理问题只交给某个人的善意。

  6. 55—60 分

    约定试行与反馈

    选择负责人及复核日期；没有真实授权时，明确这只是建议草案。

可选的开放问题

  • 谁受到影响却没有在场？
  • 规则会不会奖励占优势的人？
  • 如果安排无效，怎样承认并修改？
具体产出

一条可试行的规则，以及适用范围、责任人、异议途径和复核日期。

适用边界

本流程借鉴研究问题，不是奥斯特罗姆理论的完整操作手册，也不替代组织正式授权。

怎样复盘

观察使用冲突、维护负担与反馈是否改善，不以气氛热烈代替实际效果。

本站原创流程 / 3—8 人 · 自修小组、跨专业学习

不同知识共同面对一个问题

75 分钟

让经验、证据与伦理各自做该做的工作。

准备材料

以校园花园为假设情境，或选择一个低风险、可公开讨论的公共问题；先读星盘资料与互惠导读。

对应深读文章 ↗视频与中文导读 ↗
  1. 00—10 分

    列出真正的问题

    把“改善花园”分为植物状况、可达性、使用权、记忆意义等具体问题。

  2. 10—25 分

    对照两种资料

    一份经验记录与一份研究或机构资料。注明作者、日期、方法和适用范围。

  3. 25—40 分

    画出论证

    分别写结论、支持它的材料，以及尚未说明的价值前提。

  4. 40—55 分

    认真提出反对意见

    每组提出最强反例；避免选择容易驳倒的弱版本。

  5. 55—70 分

    设计一项小行动

    说明行动权限、所需资料、可能代价与复核方式。

  6. 70—75 分

    保留未知

    列出仍不知道的事，以及有资格补充这些知识的人或资源。

可选的开放问题

  • 哪些问题可以由测量回答，哪些仍需要协商？
  • 被引用的群体有没有真正表达自己的机会？
  • 我们是否用尊重取消了检验，或用检验取消了尊重？
具体产出

一张问题—资料—价值—行动对应表；附上两个仍开放的问题。

适用边界

不模仿未经理解和许可的神圣仪式，不代表某一群体发言，也不把讨论当作现场调查结果。

怎样复盘

看每项结论是否找到相应依据，每项行动是否说明权限与代价。

先判断适不适合

存在暴力、胁迫、危机或显著权力不对等时，不要用普通对话流程要求当事人面对面解决。优先安全与合适支持。针对真实组织的规则，讨论草案不等于获得正式授权。
